# OCP (open-closed principle)
개방-폐쇄 원칙
컴포넌트는 확장에는 열려있고 수정에 관해서는 닫혀있어야 한다.

다른 개발자가 작업을 수행하기 위해 반드시 수정해야하는
제약사항을 클래스에 포함시켜서는 안된다 라는 뜻

# 개방-폐쇄 원칙을 따르지 않은 경우
bad/AreaCalculator의 sum 메서드는 전달받은 도형 리스트에

들어있는 모든 도형의 면적을 합해서 반환하는 메서드다

도형 클래스를 추가할때마다 이 메서드의 내용을 수정해야한다.

# 개방-폐쇄 원칙을 따르는 경우
AreaCalculator에서 면적 계산 부분을 빼서

공식이 필요한 각 도형 클래스로 옮긴다.

면적 계산은 각각의 도형 클래스가 맡도록 하고,

AreaCalculator에서는 계산된 값들을 더해서 반환하도록 한다.
